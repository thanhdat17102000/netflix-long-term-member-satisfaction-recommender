Bài toán

Nhóm dùng lịch sử chấm điểm để gợi ý phim, rồi kiểm tra gợi ý bằng những lượt chấm diễn ra sau đó.

  1. Đọc dữ liệu phim và lịch sử chấm điểm của người dùng.
  2. Chia lịch sử theo thời gian để mô hình chỉ học từ các lượt chấm trước.
  3. Tạo danh sách phim bằng ba cách: phổ biến, ALS và kết hợp.
  4. Đối chiếu danh sách với các lượt chấm về sau, trong đó từ 4 sao được tính là phản hồi tích cực.

Lệnh chạy

Bạn có thể mở dashboard với dữ liệu mẫu mà không cần cài Spark.

  1. python -m src.web — mở dashboard; khi thiếu kết quả full, trang dùng dữ liệu mẫu.
  2. python -m pytest -q — chạy test, không cần Spark.
  3. bash scripts/01_upload_raw.sh --profile smoke … 08_evaluate.sh --profile smoke
  4. bash scripts/01_upload_raw.sh --profile full … 08_evaluate.sh --profile full

Muốn chạy bản đầy đủ thì cần gì

Để có kết quả full, cần chạy pipeline với đủ dữ liệu và phần mềm bên dưới.

  • Java 17, Python 3.10, PySpark 3.5.1, TensorFlow CPU 2.15.1
  • Hadoop 3.3.6 / HDFS, Spark 3.5.1
  • File dữ liệu lớn giải nén đủ 6 CSV

Khi nào dashboard hiển thị FULL?

Dashboard chuyển sang FULL khi tìm thấy artifacts/metrics/metrics.json và artifacts/recommendations/top10_recommendations.csv từ lần chạy đầy đủ. Hãy đối chiếu thêm trạng thái pipeline trước khi công bố kết quả.
